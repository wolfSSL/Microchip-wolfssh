# wolfSSH Library for Microchip

This repository contains commercially licensed wolfSSH product code
solely for use with the Microchip silicon products and/or development tools
with which our wolfSSL products are integrated.

This code is only properly licensed when following the license terms in the
license file included in the root of this repository:

[LICENSE\_WOLFSSL\_MICROCHIP\_v12052025.txt](LICENSE_WOLFSSL_MICROCHIP_v12052025.txt)

This repository contains git tags which match the wolfSSL version mentioned in
their name. For example, 'v1.6.0-commercial' is the wolfSSH 1.6.0 commercial
release.

For a description and details on the wolfSSH library, please reference the
[wolfSSH Product Page](https://www.wolfssl.com/products/wolfssh/) or
primary [GitHub repository](https://github.com/wolfssl/wolfssh).
